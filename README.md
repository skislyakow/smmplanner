# SMM Planner

Скрипт на Python для автоматического планирования и публикации контента из Google Таблиц в социальные сети.

## Содержимое репозитория

Проект имеет модульную структуру для работы с разными API:
* `scheduler.py` — основной планировщик публикаций.
* `google_sheet.py` — модуль интеграции с Google Sheets (источник постов).
* `tg_poster.py`  — публикация в Telegram.
* `vk_poster.py` — публикация в ВКонтакте.
* `ok_poster.py` — публикация в Одноклассники.

##  Быстрый старт

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python 3.8+. Клонируйте репозиторий:

```bash
git clone https://github.com
cd smmplanner
```

### 2. Установка зависимостей
Установите все необходимые библиотеки:

```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корневой директории проекта и заполните его вашими данными:

```env
# Google Sheets Configuration
GOOGLE_SHEET_ID=your_google_sheet_id_here

# Telegram Configuration
TG_BOT_TOKEN=your_telegram_bot_token
TG_CHANNEL_ID=-100xxxxxxxxxx

# VK Configuration
VK_USER_TOKEN=your_vk_api_access_token
VK_GROUP_TOKEN=group_vk_api_access_token
VK_GROUP_ID=your_vk_group_id

# OK (Odnoklassniki) Configuration
PUBLIC_KEY_OK=your_ok_app_key
SECRET_KEY_OK=your_ok_secret_key
ACCESS_TOKEN_OK=your_ok_access_token
GROUP_GID_OK=your_ok_group_id
```
> **Важно**: Также положите файл `service_account.json` (сервисный ключ Google API) в корень проекта для работы с Google Таблицами.

### 4. Запуск планировщика
Запустите основной исполняемый файл для старта проверки расписания:

```bash
python scheduler.py
```

##  Формат Google Таблицы

Для корректной работы планировщика ваша Google Таблица должна строго содержать следующие столбцы в первой (заголовочной) строке:


| Столбец | Название заголовка | Описание | Пример заполнения |
| :--- | :--- | :--- | :--- |
| **A** | `VK Отправить` | Флаг для публикации в VK | `Да` / `Нет` |
| **B** | `VK Статус` | Статус публикации (заполняет скрипт) | `Опубликовано` / `Ошибка` |
| **C** | `VK id` | Идентификатор поста в VK (заполняет скрипт) | `wall-12345_678` |
| **D** | `OK Отправить` | Флаг для публикации в Одноклассники | `Да` / `Нет` |
| **E** | `OK Статус` | Статус публикации в ОК (заполняет скрипт) | `Опубликовано` |
| **F** | `OK id` | Идентификатор поста в ОК (заполняет скрипт) | `67890` |
| **G** | `TG Отправить` | Флаг для публикации в Telegram | `Да` / `Нет` |
| **H** | `TG Статус` | Статус публикации в TG (заполняет скрипт) | `Опубликовано` |
| **I** | `TG id` | Идентификатор сообщения в TG (заполняет скрипт)| `1024` |
| **J** | `Текст поста` | Текстовое содержимое вашей публикации | `Роза. Королева цветов...` |
| **K** | `Фото поста` | Прямая ссылка на прикрепляемое изображение | `https://example.com` |
| **L** | `Дата публикации`| Дата и время запланированного выхода поста | `23.05.2026 18:35:00` |
| **M** | `Удалить` | Флаг для удаления поста со стен/каналов | `удалён` / оставить пустым |
| **N** | `Дата удаления` | Дата и время запланированного удаления поста | `23.05.2026 18:36` |

>  **Важно**: Регистр букв и пробелы в названиях колонок первой строки должны точно соответствовать указанным выше, так как скрипт обращается к ним по именам.


##  Как это работает

1. **Контент-план**: В своей Google Таблице вы заполняете необходимые для постов данные в соответсвии с приведенным выше шаблоном. 
2. **Сбор данных**: Модуль `google_sheet.py` считывает новые строки и форматирует текст постов.
3. **Публикация**: `scheduler.py` проверяет текущее время и вызывает нужные постеры (`tg_poster.py`, `vk_poster.py`, `ok_poster.py`) для отправки контента.
